# Changelog

## 1.0.0 - 2026-10-29

- Initial installable PersonVault build with PHP 8.5, SQLite, and MySQL support.
- Added per-user contacts, managed accounts, personal journals, and relationship events.
- Added authenticated record encryption, session and CSRF protection, owner-scoped access, trash recovery, and encrypted JSON exports.
- Added first-run setup, installation lock, responsive light/dark themes, autosave, and an executable PHP test suite.
